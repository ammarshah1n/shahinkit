# Mission

Thin entry to `plans` with `MISSION` pinned and `research=hybrid` by default. Use only when outputs share a coherence spine; ambition alone is not coupling.

1. Set mission anchor and retrieve memory first. Preserve only distilled, redacted evidence in durable project storage; reject raw transcripts, private paths, credentials, and personal memory before analysis.
2. Build one thesis brief: proof-user outcome, current state, shared research, locked decisions, non-goals, and output scopes.
3. Produce one plan per deliverable from same thesis brief. Each plan includes thesis fit (`supports`, `depends on`, `must not contradict`), research decision, dependency graph, parallel batches, correctness gates, spec-drift, and delete/merge analysis.
4. Research every critical external unknown before review. Shared unknowns are researched once; plan-local unknowns stay local.
5. Run per-plan adversarial review plus cross-pack consistency review. Produce contradiction table covering duplicated work, incompatible decisions, and cross-plan dependencies. Controller adjudicates findings.
6. Present complete pack, observed evidence for critical assumptions, contradiction table, and named human blockers. Wait for one explicit `GO` before implementation.

If outputs prove independent, stop mission mode and route to `plans`.
