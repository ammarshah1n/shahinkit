# Corrections

Use when user corrects an error, rejects an approach, or states durable preferred behavior.

## Procedure

1. Stop current approach and acknowledge specific correction.
2. Identify mistake, correct behavior, and evidence available before mistake.
3. Check `CORRECTIONS.md` for same prevention rule.
4. Add or update concise dated entry using shared template.
5. Apply corrected behavior now when scope permits.

## Rule Quality

- Record generic, actionable prevention rule; omit personal, domain, project, and session-only detail.
- Never store or copy raw transcripts, transcript exports, or raw tool output.
- Do not silently turn correction into broad policy. Escalate policy changes for explicit review.
