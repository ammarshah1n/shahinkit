# Wrap Up

Close the current ShahinKit session.

1. Run `wrap-up` for substantial work or `miniwrap` for a tiny task.
2. Update `BUILD_STATE.md`, `HANDOFF.md`, `NEXT.md`, and `SESSION_LOG.md` when present.
3. Record verification commands and results.
4. Commit only if the project rules require it.

Do not paste raw transcript content into handoff or memory files.
