# Codex Skills

Portable ShahinKit skills live in `shared/skills/`.

For a local Codex installation, copy the selected skill folders into the user's Codex skills directory or point the install process at `shared/skills/` when supported.

Recommended set:

- `new-idea`
- `deep-plan`
- `prime`
- `wrap-up`
- `miniwrap`
- `checkpoint`
- `ingest-large-folder`
- `rag-consent`

Keep the skill bodies identical to `shared/skills/` unless a client compatibility issue requires an adapter-specific note.
