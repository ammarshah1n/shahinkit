# `/idea`

Use the `idea` skill for one net-new idea.

Expected shape:

1. Clarify the proof user and outcome.
2. Search configured memory and existing files.
3. Check whether the idea should be built, deferred, or rejected.
4. Produce a PRD and build context when the idea survives validation.
5. Hand off to `plan` or `deep-plan` for implementation planning.
