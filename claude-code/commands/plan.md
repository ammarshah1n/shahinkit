# `/plan`

Use the `plan` skill for one non-trivial change.

Expected shape:

1. Set the goal and success criteria.
2. Retrieve configured memory if available.
3. Inspect relevant files.
4. Draft alternatives and pick a recommended approach.
5. Write a dependency graph and parallel batch schedule.
6. Review the plan for missing tests, overengineering, and risky assumptions.
7. Present the final plan for approval before implementation.
