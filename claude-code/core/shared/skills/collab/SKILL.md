# Collab

1. State review target, acceptance criteria, and non-negotiable constraints.
2. Obtain independent critiques when available; otherwise perform clearly separated review passes.
3. Compare findings against source evidence, resolve conflicts, and keep only actionable issues.
4. Return agreed strengths, risks, required fixes, and unresolved decisions; do not treat critique as proof.
5. If independent review capability is unavailable, report that limitation honestly.
6. Never automatically install, commit, push, publish, submit, send, book, pay, delete, or mutate an external system. Require explicit user approval.
