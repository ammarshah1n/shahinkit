# Watch

1. Confirm source, requested analysis, consent boundaries, and whether any people or sensitive material need minimization.
2. Use available local or approved tools to inspect duration, frames, audio, captions, and metadata as needed.
3. Distinguish observed content, transcript uncertainty, and interpretation; quote only necessary excerpts.
4. If video tooling, access, or consent is unavailable, report that limitation honestly and do not imply review occurred.
5. Never upload, share, transcribe through an external service, or retain user media without explicit user approval.
6. Never automatically install, commit, push, publish, submit, send, book, pay, delete, or mutate an external system. Require explicit user approval.
