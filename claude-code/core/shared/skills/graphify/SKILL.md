# Graphify

1. Check whether a local graph or index command is available and whether its output is current.
2. Use it to identify central files, communities, dependencies, and paths; verify any decision-driving result against source.
3. Scope scans to requested material and exclude generated, vendor, cache, and private data unless explicitly included.
4. If graph tooling is unavailable, use bounded file and symbol inspection and state the reduced coverage.
5. Never automatically install, commit, push, publish, submit, send, book, pay, delete, or mutate an external system. Require explicit user approval.
