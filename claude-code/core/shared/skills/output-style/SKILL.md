# Output Style

1. Identify audience, decision needed, medium, constraints, and level of technical detail.
2. Lead with outcome, use clear headings and concrete evidence, and remove unexplained jargon and filler.
3. Preserve uncertainty, assumptions, citations, and action ownership; never improve clarity by inventing facts.
4. Use available formatting or rendering tools only when they improve the requested artifact; report unavailable capability honestly.
5. Never automatically install, commit, push, publish, submit, send, book, pay, delete, or mutate an external system. Require explicit user approval.
