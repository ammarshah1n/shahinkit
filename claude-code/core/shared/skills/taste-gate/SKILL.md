# Taste Gate

1. Read intended audience, objective, constraints, and acceptance criteria before judging presentation.
2. Inspect actual rendered output when a renderer is available; otherwise report unavailable rendering and limited visual confidence.
3. Check clarity, hierarchy, precision, consistency, accessibility basics, and whether content earns user attention.
4. Return only concrete keep, fix, and decision-needed findings; do not substitute preference for requirements.
5. Never automatically install, commit, push, publish, submit, send, book, pay, delete, or mutate an external system. Require explicit user approval.
