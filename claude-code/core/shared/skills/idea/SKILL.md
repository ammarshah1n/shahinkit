# Idea

Thin entry to `plan` with `IDEA` pinned and `research=hybrid` by default. Do not duplicate planning spine here.

1. Set goal anchor and retrieve memory before research.
2. State proposition, proof-user, existing alternative, adoption evidence, and kill criterion.
3. Research only decision-changing unknowns. Inspect buy, reuse, integrate, and fork candidates before proposing custom build.
4. Produce validation verdict: `BUILD`, `DON'T-BUILD`, or `NOT-NOW`, with evidence for, evidence against, and kill-criterion result.
5. For `BUILD`, produce PRD/build context, then run `plan` shared spine: approaches, dependency graph, parallel batches, spec-drift, delete/merge, adversarial review, correctness gates, and explicit GO.

If substantial relevant implementation already exists, state reclassification and run `plan` as `CHANGE`. `DON'T-BUILD` and `NOT-NOW` are complete outcomes; no implementation follows them.
