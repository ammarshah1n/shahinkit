# Research

1. Define question, decision it supports, freshness requirement, and claims that require evidence.
2. Prefer primary sources, official documentation, original records, and directly inspectable evidence; distinguish them from commentary.
3. Compare sources, record dates and uncertainty, and cite each decision-driving claim with its source.
4. If approved research access or a needed service is unavailable, report the gap honestly rather than fabricating current evidence.
5. Never automatically install, commit, push, publish, submit, send, book, pay, delete, or mutate an external system. Require explicit user approval.
