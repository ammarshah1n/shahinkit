# Triage

1. Restate requested outcome, in-scope surfaces, exclusions, success check, and missing decisions.
2. Classify risk: routine, sensitive, external, destructive, or integrity-critical.
3. Choose smallest safe route: answer, inspect, research, implement, review, or ask one blocking question.
4. Check required local command or service prerequisites before promising verification; report unavailable capability honestly.
5. Never automatically install, commit, push, publish, submit, send, book, pay, delete, or mutate an external system. Require explicit user approval.
