# Skill Builder

1. Define trigger phrases, user outcome, boundaries, inputs, and smallest reusable workflow.
2. Reuse existing capabilities conditionally; avoid host, account, path, model, service, and project assumptions.
3. Write concise frontmatter and instructions that say what happens when an optional command or service is unavailable.
4. Add only checks that prove trigger, safety boundary, and essential output; cut speculative scaffolding.
5. Never automatically install, commit, push, publish, submit, send, book, pay, delete, or mutate an external system. Require explicit user approval.
