# Disabled Optional MCP Examples

These files are catalog templates, not host configuration fragments. Each
entry remains disabled and uses only placeholders for endpoints, command
arguments, environment variables, or operator-owned secret files.

Do not put a secret value in an argument, repository file, receipt, log, or
host instruction. Secret file placeholders name a local file reference; they
do not authorize reading or copying its content. Enable an integration only
after user approval and a host-specific review.
