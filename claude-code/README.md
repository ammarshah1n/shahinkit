# Claude Code Kit

This folder contains the Claude Code version of ShahinKit.

Start with `CLAUDE.md`, then copy the skills you want from `skills/` into your Claude Code skills directory or keep them in a project-level skill folder if your setup supports it.

Useful entrypoints:

- `CLAUDE.md` - global/project instruction template.
- `skills/` - portable skill workflows.
- `commands/` - slash-command prompt notes for Claude Code.
- `config/` - example settings fragments.
- `hooks/` - opt-in hook examples.
- `course-rag/` - local course-folder search builder.
