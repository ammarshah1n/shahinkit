## Excluded

Never copied:

- access/refresh tokens, API keys, auth files, browser session material;
- sessions, caches, model stores, logs, trust state, backups, conflicts,
  generated results, or personal memory;
- active settings/model/MCP files containing personal defaults, local paths,
  private endpoints, or OAuth configuration;
- installed `node_modules` and local edits inside authentication packages;
- institution-specific network routing, local transcript/status relays,
  clipboard forwarding, and third-party conversation compaction;
- private-hardware/network model profiles, runtime snapshots, benchmarks, and
  machine-specific local-model documentation;
- GUI-driven deep-research automation;
- retired and `.orig-*` extension copies.

These are functionality or data-loss/privacy boundaries, not missed files.

## Safety changes

- Remote subagents are now unconfigured by default.
- Remote roots require an explicit semicolon-separated
  `PI_REMOTE_SUBAGENT_MAP`; paths outside it remain local in the extension or
  fail loudly in `pi-bg`. Remote paths are canonicalized at execution time so
  symlinks cannot escape an allowed root.
- `pi-bg` uses mode-private artifacts locally and remotely, fails closed when
  default worktree creation fails, records and validates per-job cleanup and
  process-identity metadata, uses a valid temporary Git index for diffs, blocks
  partial diffs, and refuses to clean running or uncollected jobs without
  explicit force. Prompts travel through private files, not process arguments.
- Model, tool, cache, status, and remote diagnostic text is stripped of terminal
  control and bidirectional-override characters before public terminal/UI output.
- HUD weather requests are opt-in; Fast Mode defaults off until explicitly enabled.
- Personal historical session/efficiency reports were removed from the public
  snapshot.
- Receipt and kill-switch paths follow the active Pi config.
- Public files were scanned for personal paths, private endpoints, credential
  assignments, and private-key blocks; none were found in the updated surface.
- Source hashes confirmed the portable live files were not modified.
