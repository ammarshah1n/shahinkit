# Pi portability audit — 2026-10-09

Refresh of the public `Pi/` snapshot against the live setup, 2026-09-03 → 2026-10-09.
Method: features were re-implemented on top of the hardened snapshot files.
No live file was copied over a snapshot file, so the snapshot's terminal-output
sanitization, project-trust gate, private task-file transport, strict worktree
failure, uncollected-work protection, and allowlist-only remote stay intact.

## Ported

- **Working rules** (all four hosts: `claude-code/CLAUDE.md`, `codex/AGENTS.md`,
  `opencode/AGENTS.md`, `Pi/AGENTS.md`): automatic brief play-back on
  task-opening prompts; questions are not work; explicit handoff mode; batch
  rule; runaway guard (DONE/NOT DONE status answers, one review round,
  bookkeeping is not work, >20 mutations incl. shell writes → dispatch);
  smallest-first planning with a 3-milestone default cap; consumer-grade ≠
  enterprise-grade; Brave/Exa web routing.
- `FABLE-MODE.md` + `fable-mode.ts`: Astra counts as controller-tier; questions
  are not work; handoff override; small write units; budgeted fan-out.
- `bin/web`: Brave search (default) + Exa research + free fetch, env/keyfile/
  keychain keys, optional `WEB_PROXY`.
- `pi-bg-notify.ts` + `bin/pi-bg`: whitespace-token job ids, `NOT TRACKED`
  notice, per-session `.owner` sweep (start + every 30 s, once-only), `/bg`.
- `subagent/index.ts`: multi-task calls forced to background, blocking-child
  timeout (`PI_SUBAGENT_TIMEOUT_MIN`, default 10), partial output on abort.
- New `turn-budget.ts`, `auto-title.ts`, `image-cap.ts`, each with a test.
- `hud.ts`: deduped quota history + `/quota`, last-good-value retention.
- `fast-mode.ts`: Astra never gets priority tier; `double-escape-clear.ts` and
  `abliteration.ts` live fixes.
- Agent profiles: GPT-6 Luna/Sol and Opus 5.5 pins; `plan-reviewer` gains
  cut-don't-add, cost-of-scope, and ponytail-at-plan-time checks.

## Deliberately not ported

- Private: institution network proxies, private-host routing and remote maps,
  host doctor, confidential-data agent roster and EU-only routing, personal
  finance/media/printing skills, bulk-fleet skill, personal postmortems.
- Still excluded for the 09-03 reasons: GUI-driving deep-research, RTK adapter,
  private-hardware model profiles, clipboard paraphrase, third-party
  conversation compaction.
- Live `wrap-up` 11-phase auto-commit/push workflow (contradicts the snapshot's
  approval-gated wrap-up) and the personal-setup `/plan` rewrite; only its
  ponytail/milestone-cap doctrine moved over.
- Live removals of safety features (see Method) were not mirrored.
