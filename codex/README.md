# Codex Kit

This folder contains the OpenAI Codex version of ShahinKit.

Start with `AGENTS.md`, then copy the skills you want from `skills/` into your Codex skills directory or into a project-local skill folder if your setup supports it.

Useful entrypoints:

- `AGENTS.md` - global/project instruction template.
- `skills/` - portable skill workflows.
- `config/` - example Codex config fragments.
- `hooks/` - opt-in hook examples.
- `course-rag/` - local course-folder search builder.
