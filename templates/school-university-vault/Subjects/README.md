# Subjects

This vault starts with five generic subject folders:

- `Subject 1`
- `Subject 2`
- `Subject 3`
- `Subject 4`
- `Subject 5`

Rename them to your real subjects. If you do not want to do that manually, tell your agent the subject names and ask it to rename the folders.

Use the same structure inside each subject:

- `Lessons/`
- `Readings/`
- `Notes/`
- `Sources/`
- `Assessment/`

For more or fewer subjects, duplicate or remove subject folders after confirming the change.
