# OneDrive Imports

Temporary holding area for imported files.

## Sort Process
1. Identify subject or assignment.
2. Move the file into the correct folder.
3. Add a short note in the relevant index.
4. Remove duplicates after confirming the sorted copy.

## Large Database Or Export

You can give the agent a large school folder, zip, OneDrive export, or document database and ask it to run `ingest-large-folder`.

Expected flow:

1. Inventory the file or folder first.
2. Show file counts, major file types, and proposed exclusions.
3. Ask before extracting, moving, installing indexing tools, embedding, or indexing.
4. Install or use the required local RAG tooling only after approval.
5. Embed only the approved school materials into the school RAG corpus.
6. Write the consent record and rebuild/revoke instructions.

## Do Not Keep Here
- Final submissions.
- Long-term sources.
- Private or irrelevant files.
