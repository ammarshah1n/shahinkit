# Vault Index

## Read Order
1. `Working-Context/project-state.md`
2. `NEXT.md`
3. `HANDOFF.md`
4. `03 - Specs/index.md`
5. `06 - Context/index.md`
6. Relevant rule, walkthrough, prompt, error, or template notes.

## Folder Map
- `00 - Rules/`: durable operating rules and constraints.
- `01 - Walkthroughs/`: repeatable procedures.
- `02 - Prompts/`: reusable agent prompts.
- `03 - Specs/`: product, feature, and implementation specs.
- `04 - Errors/`: error reports, diagnoses, and fixes.
- `05 - Dev Log/sessions/`: chronological session notes.
- `06 - Context/`: architecture, decisions, and background context.
- `07 - Templates/`: reusable document and prompt templates.
- `Working-Context/`: current state, next actions, and handoff notes.
- `Archive/`: obsolete or superseded material.

## Do Not Read By Default
- `Archive/` unless current files point there.
- `05 - Dev Log/sessions/` unless debugging session history.
- Drafts, imports, conversation logs, and raw logs unless explicitly requested.

## Agent Entry Points
- Start with `Working-Context/project-state.md`.
- Use `NEXT.md` for the immediate task queue.
- Use `HANDOFF.md` when resuming after a pause.
- Check `00 - Rules/index.md` before editing project behavior.
