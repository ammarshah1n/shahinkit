# Private Data Exclusions

Never index, export, or commit these data types:

- Secrets, API keys, tokens, credentials, and recovery codes.
- Raw transcripts and unredacted session logs.
- Private local paths and device-specific paths.
- Personal identifiers not required for an approved deliverable.
- Client-private details without explicit approval.
- School records not needed for the current route.
- Financial, medical, legal, or identity documents unless explicitly approved.

Default action: exclude and ask for a narrower source.
