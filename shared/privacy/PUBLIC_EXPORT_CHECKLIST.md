# Public Export Checklist

Complete before anything leaves the private workspace.

- [ ] Export path is listed in `shared/rag-indexing/PUBLIC_EXPORT_ALLOWLIST.md`.
- [ ] Source has opt-in consent.
- [ ] Redaction checklist is complete.
- [ ] Private data exclusions were applied.
- [ ] Output contains no secrets, raw transcripts, private local paths, or personal identifiers.
- [ ] Export contains only the intended files.
- [ ] Reviewer recorded approval date and scope.
